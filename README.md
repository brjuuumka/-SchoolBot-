# 🤖 SchoolBot – Телеграм-бот для школы

Бот для учёта успеваемости, посещаемости, домашних заданий и коммуникации между учителями, учениками и родителями.

## 🚀 Функциональность

- **Администратор**: регистрация пользователей, рассылка, просмотр расписания, статистика.
- **Учитель / Классный руководитель**: выставление оценок, отметка пропусков, замечания, домашние задания, объявления классу.
- **Ученик**: оценки, расписание, домашние задания, замечания.
- **Родитель**: успеваемость ребёнка, статистика за неделю, связь с классным руководителем.
